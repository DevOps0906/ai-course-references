### 3-7. stack_visualizer.html (원본 직접 확인)
원문 제목(`<title>`): **"배열 스택 실행 추적기 · stack.c"**

- **무엇을 하나**: 왼쪽에 **편집 가능한 C 소스(stack.c)**, 오른쪽에 `int stack[MAX]` 메모리 칸과 `top` 포인터를 그려 **push/pop/peek 실행을 단계별로 추적·애니메이션**하는 스택 시각화 도구. 외부 라이브러리 없는 단일 HTML.

- **핵심 함수**
  - `parseProgram(src)`: 정규식으로 `#define MAX` 값(표시 범위 1~8로 클램프), 함수 블록 위치(push·pop·peek·isFull·isEmpty·main), 각 함수 내 핵심 라인(`top++`, `stack[top] =`, `top--` 등), `main()` 안 연산 순서를 추출. **실제 C 컴파일·실행이 아니라 패턴 기반 시뮬레이션.**
  - `buildTrace(src)`: 연산마다 호출→진입→isFull/isEmpty 검사→증감→저장/읽기→복귀를 스냅샷(`steps`)으로 생성, 한국어 설명 문장 포함(예: "top = -1 은 … 배열 밖을 가리킵니다").
  - `render(i)`: 현재 코드 줄 하이라이트·자동 스크롤, 칸 채움/top 강조, `[-1]` "배열 밖" 팬텀 칸, 배지(PUSH/POP/PEEK/READ/CHECK/FULL/EMPTY), 연산 로그.
  - `animateOp()`·`floatChip()`: push 초록/pop 빨강/read 파랑/peek 주황 플래시와 "+값/−값" 칩.
  - 컨트롤: 처음·이전·재생(1.15초 간격)·다음·스크럽 슬라이더, 키보드 ←/→/Space, `prefers-reduced-motion` 대응.

## 6. 특이사항

- **중복 파일**: `강의계획서_자료구조와알고리즘_샘플.docx`가 1일차·2일차에 동명으로 존재하나 **내용 1줄(6주차 "·후위 표기 변환") + 메타데이터 시각만 다른 개정본**(3-9 참조).
- **샘플 자료 성격**: 모든 docx는 교육용 가상 자료. 가상학생제출물은 "실존 학생이 아닌 교육용 가상 제출물"로 명시, 학생명도 "학생 B, 학생 B′". 과제안내문은 일부러 정보가 빠진 "나쁜 원본", 강의계획서 학습목표는 일부러 금지 동사로 작성, 학생 제출물에는 일부러 교차 케이스 버그 — **실습용 함정이 설계된 자료**.
- **워크북과 부속 파일의 연결성**
  - gesture.html(포니봇 제스처 제어)은 3개 워크북 어디에도 언급되지 않음 — 판서 7번 슬라이드에서만 링크. 바이브코딩 시연용 보너스 데모로 추정.
  - stack_visualizer.html도 워크북에 직접 언급 없음. 판서 5번 슬라이드의 별도 저장소(stack_test)와 같은 계열의 도구로 보임(추정).
  - gesture.html 주석의 `ble_library.py`(로봇 측 펌웨어)는 zip에 **없음**.
  - 2일차 실습 3에서 "학생 A·C 요약"은 Claude로 생성하는 구조라 별도 파일 없음(정상).
- **시간 표기 차이**: 판서 1번 슬라이드는 "45분 수업, 15 휴식"이지만 워크북 시간표는 50~70분 교시 + 5~10분 휴식으로 다름.
- **판서 코드 오류**: 6번 슬라이드 C 코드는 컴파일되지 않는 상태(`temp` 미선언 등) — 판서 의도(오류 시연)로 추정되나 배포 자료로 쓸 경우 주의.
- **CDN 버전 미고정**: gesture.html의 MediaPipe 스크립트가 버전 없이 로드되어 향후 라이브러리 업데이트 시 동작이 바뀔 수 있음.
- **민감정보 노출 여부**
  - 판서.pptx 1번 슬라이드에 **강사 실명·이메일 노출됨(마스킹)**.
  - 판서.pptx 문서 속성(작성자·마지막 수정자)에 **실명으로 보이는 값 노출됨(마스킹)**. docx 5종의 작성자는 "Un-named"로 개인정보 없음.
  - 강의계획서·과제안내문·기출의 담당교수 이름·이메일은 가상 예시(이메일은 example 도메인) — 실존 개인정보 아님으로 보이나 원문 값은 옮기지 않음.
  - form_link의 구글폼 ID는 공개 응답 링크로, 외부 공유 시 응답 수집 범위 확인 필요.
  - API 키·토큰·비밀번호: **없음**. gesture.html의 UUID는 BLE 표준(Nordic UART) 식별자로 비밀정보 아님.

## 7. 활용 포인트

1. **"교수자용 Claude 3일 연수" 강의 상품** — 워크북 3종이 시간표·퀴즈·정답·심화 미션까지 완성형이므로, 전공 치환 가이드(화학·수학 예시 이미 포함)만 덧붙여 대학 교수학습지원센터 B2B 연수 상품으로 패키징.
2. **전자책 『AI로 수업 설계부터 평가까지 — 교수자를 위한 Claude 프롬프트 워크북』** — [교수 확인 필요] 기법, 환각 사냥 게임, 루브릭 시운전, 신호등 규칙, 윤리 6원칙을 장별로 재구성(디지털노마드연구소 교육 라인업과 직결).
3. **템플릿 팩 판매** — 프로젝트 지침 템플릿, 과제 명세서 양식(입출력 명세·[교수 확인 필요]), 4수준 루브릭+anchor 표, 피드백 뱅크, AI 사용 기록 양식, 교수 프로토콜 A4 양식을 docx/노션 템플릿으로.
4. **교육용 인터랙티브 시뮬레이터 SaaS/라이브러리** — stack_visualizer의 "편집 가능 코드 → 단계 추적 애니메이션" 구조를 큐·연결 리스트·BST·레드-블랙 트리로 확장해 강의용 시각화 도구 구독 서비스나 전자책 부록 웹앱으로.
5. **피지컬 AI 입문 키트 콘텐츠** — gesture.html(MediaPipe 손 인식 + Web Bluetooth ESP 로봇 제어)을 "브라우저만으로 하는 제스처 로봇" 실습으로 확장해 JARVIS/피지컬 AI 강의나 바이브코딩 커리큘럼의 데모 챕터로 재활용.
