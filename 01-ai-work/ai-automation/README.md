## 6. 특이사항

- **중복 파일**: 없음. 3개 모듈이 각각 독립 파일.
- **샘플 자료 성격**: 실습 데이터가 모두 본문에 **인라인 가상 데이터**로 포함(별도 xlsx/csv 첨부 없음) — 특강 메모, 회의 녹취 메모, 비교과 실적 CSV 8행 등. 의도적 함정 데이터 포함(빈 참여인원, "에코백" 미결정 사항).
- **누락·미확정 표기**
  - 실습 도구: "실습 도구는 협회 지원 확정 후 안내 예정", "AI 모듈 — 당일 안내되는 도구 사용", "계정 세팅 가이드는 별도 배포" → **계정 세팅 가이드 파일은 zip에 없음**.
  - 1-3·2-1 제목에만 "(1H)" 시간 표기가 있고 1-1·1-2·2-2·3-1·3-2 제목과 3-3의 STEP 소제목들은 끝에 공백만 남아 있음 — 시간 표기를 지운 편집 흔적(추정).
  - 모듈 1 빈칸 ② 해설에 "**3일차… 아니, 모듈 3-3**에서" 라는 문구 — 과정 일수 변경(3일→2일) 흔적으로 보임(추정). 1-3 빈칸 ⑦에는 "Day 2 오후"로 표기.
  - 과정 구분이 "2일"로 명시되나 각 모듈의 일차 배정은 명시되지 않음.
- **민감정보 노출 여부**: API 키·토큰·실명·개인 연락처 **없음**. 전화번호는 `053-XXX-XXXX`로 이미 마스킹, 학번 예시도 `20XX1234`. 회의 참석자는 직함형 가명(김팀장·박선생 등). 기관명(계명문화대학교)만 실명 노출.

## 7. 활용 포인트

1. **"교직원 AI 업무자동화 2일 패키지" 강의 상품화** — 모듈 구성·시간표(3-3의 150분 표)·치트시트가 완성형이므로, 공공기관/중소기업 사무직용으로 예시만 치환해 B2B 출강 상품으로 재포장.
2. **전자책 『프롬프트 카드 50 + 자동화 레시피』** — R-C-T-F-C 카드, 교정 프롬프트, 메일 답장 씨앗 5종, FAQ 템플릿을 업무별 카드북으로 정리(디지털노마드연구소 전자책 라인업).
3. **노션/구글시트 템플릿 판매** — "AS-IS/TO-BE 자동화 기획서 + 4기준 점수표(14점 컷)" 자동계산 시트, 주간보고 `{{ }}` 템플릿, KPI 대시보드 3층 템플릿.
4. **동일 시나리오 3도구 비교 실습을 SaaS 온보딩 콘텐츠로** — "폼→시트→LLM→메일" 시나리오를 Make 블루프린트·n8n 워크플로 JSON으로 배포하는 미니 제품(또는 NOMAD Funnel Engine 류 CRM의 문의 자동응답 기능 데모)으로 활용.
5. **"민원/문의 AI 분류+답변 초안" 마이크로 SaaS** — 3-3 응용 시나리오(Human-in-the-loop, 초안을 담당자에게 발송)를 그대로 제품 기획으로 확장 가능.
