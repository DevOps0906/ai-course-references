| 정제실습 | A1:D9 | 8행 × 4열 | 고객명·날짜·금액·지역 | 없음 | 5-1·7교시 정제 — 앞뒤 공백, `2024/01/06`·`24.1.7`·`1/9/2024` 혼재, `₩`·콤마, 공백 이름 행, 완전 중복 1건(김철수) + 공백 제거 후 중복 1건(이영희) |
| 1월 | A1:D10 | 9행 × 4열 | 날짜·제품·수량·금액 | 없음 | 6-2 시트 통합 |
| 2월 | A1:D7 | 6행 × 4열 | 동일 | 없음 | 6-2 |
| 3월 | A1:D7 | 6행 × 4열 | 동일 | 없음 | 6-2 (9+6+6 = 21행) |

- 차트·이미지·데이터 유효성·조건부 서식·병합 셀·정의된 이름: **모두 없음**(학습자가 실습으로 만드는 구조).
- 수식은 워크북 전체에서 **제품마스터 D2:D6의 5개뿐**(`=_xlfn.XLOOKUP(A2, 제품마스터!A:A, 제품마스터!B:B)` 형태, 캐시값 = 제품명). 교재에는 이 D열에 대한 설명이 없음.
- 파일 속성: 작성 프로그램 `openpyxl`(2026-07-12 생성) → 이후 Excel에서 저장(마지막 수정자 메타데이터 존재). 파이썬으로 생성 후 엑셀로 손본 것으로 보임(추정).

## 6. 특이사항

- **중복 파일**: 없음.
- **샘플 자료 성격**: 전부 **가상 데이터**(영업1~3팀, 서울·부산·대구·인천·광주, 노트북·태블릿 등 5개 제품, A상사~E마트, 김영업·이기획 등 직무형 가명). 정제실습 시트는 의도적 오류 데이터. 5-2의 이메일·전화 예시는 더미 문자열.
- **교재 체크포인트 검증 결과(openpyxl 재계산)**: 2-1 110,020,000 / 2-2 6건·11,400,000 / 2-4 38건 / 3-2 지역별 총매출 / 4-2 구성비 48.9·38.1·10.1·1.8·1.1% / 4-3 +4.5% / 5-3 83·50·67건, 서울·마우스 13건 / 6-3 제품별 행 수 / 6-4 지역별 행 수 / 6-5 부서별 합계 / 월별 매출·누계 978,280,000 — **모두 실제 데이터와 일치**.
- **누락(미기입 체크포인트)**: 1-4 STEP 4의 "서울 노트북 총매출 **[■ 실습 파일로 검증 후 기입]**"이 비어 있음(교재 말미 v2 메모에도 "기입 필요"). 실제 데이터로 계산하면 **B2:B201 = 86,400,000원 (6건)**, 원래 수식 범위 **B2:B100 = 34,800,000원** → 차이 51,600,000원이 "누락된 행의 금액". 교재의 대체 멘트("6건이 모두 100행 안에 있을 경우")는 해당하지 않음.
- **교재–파일 불일치**
  - 교재 시트 구성표는 매출데이터 사용 실습에 4-1을 넣었으나 4-1은 새 가상 데이터를 생성하는 실습이고, 반대로 5-4·5-5·6-3~6-5(매출데이터 사용)는 표에서 빠져 있음.
  - 제품마스터 D열에 교재에 없는 XLOOKUP 수식 5개가 남아 있음(제작 중 테스트 잔재로 추정). 2-5 실습은 주문내역 D·E열에 수식을 넣는 구조라 실습 진행에는 지장 없음.
  - 5-2 예시 데이터(A2 주소, D2 코드)는 xlsx에 시트로 제공되지 않아 직접 입력해야 함.
  - 실습4-4_손글씨이미지.png는 교재 본문 어디에도 언급되지 않음(교재는 "아무 문서/PDF의 표를 스크린샷으로 캡처"라고만 안내).
- **데이터 형식 주의**: 매출데이터의 날짜는 날짜형이지만 1월·2월·3월·고객RFM·정제실습·근태의 날짜/시각은 **텍스트**로 저장 — 근태는 교재가 TIMEVALUE로 대응, 고객RFM의 `=DATE(2024,6,30)-B2`는 엑셀의 텍스트→날짜 자동 변환에 의존(추정).
- **매크로**: 배포 파일은 .xlsx(매크로 없음). 6교시에서 학습자가 .xlsm으로 저장해야 함.
- **민감정보 노출 여부**: API 키·토큰 없음. 교재·시트 데이터에 실존 개인정보 없음. 단, **xlsx 문서 속성의 '마지막 수정자'에 실명으로 보이는 값이 노출됨(마스킹)** — 배포 전 문서 속성 정리 권장.

## 7. 활용 포인트

1. **"검증값 내장형" 엑셀×AI 실습 키트 판매** — 교재가 체크포인트 45건 전수 검증을 명시하고 주요 수치 재계산도 일치하므로, xlsx + 정답 시트(체크포인트 자동 대조 수식)를 추가해 "채점되는 실습 파일" 템플릿 상품으로.
2. **전자책 『AI 엑셀 프롬프트 레시피 33』** — 33개 실습을 "상황→프롬프트→받은 함수→검증값" 4단 카드로 재구성하고 템플릿 16선·오류 해결표를 부록화. 1-4 미기입 값(86,400,000)도 채워 완성본으로.
3. **7교시 "월간 경영 보고서 7단계"를 SaaS 기능으로** — 업로드한 매출 파일에 진단→정제→분석→시각화→예측→보고를 자동 실행하는 리포트 생성기(SellingStudio·GlobalSeller OS 같은 커머스 SaaS의 셀러 리포트 모듈로 이식 가능).
4. **이미지→표 변환 미니 도구** — 4-4의 인쇄 표·손글씨 메모 2종을 데모 입력으로, "종이 재고 메모 → 발주 필요 품목 표" 자동화(n8n/Make + Vision 모델) 템플릿.
5. **VBA 6종 + 버튼 대시보드를 "원클릭 업무 자동화 팩"으로** — 시트 통합/분리/대화형 추출/요약 대시보드를 범용화해 소상공인·사무직용 .xlsm 템플릿으로 판매하거나 강의 보너스 자료로 제공.
