# 벤치마크 패턴 지도 (추상화)

학습·문제풀이 서비스 4곳(학습 세트형 A, 코딩테스트형 B, 문제은행형 C, 게임화 언어학습형 D)의 공개 자료에서 뽑은 **패턴**만 적는다.
원문 문구·이미지·코드·회사명은 저장소에 두지 않는다(platform-docs LANDING_PERSUASION §1). 원본 recon 메모는 gitignore된 `.cache/benchmark/`에 있다.

> 한계: 4곳 모두 JS 렌더링이거나 자동 접근을 막아서, 랜딩 섹션 순서와 로그인 배치는 신뢰도가 낮다. 여러 곳에서 겹쳐 나온 패턴만 채택했다.

## 채택

| # | 패턴 | 근거(겹친 곳) | 우리 적용 위치 |
|---|---|---|---|
| P1 | 가입 전에 먼저 풀어 보기. 로그인은 '저장'할 때 묻는다 | A·B·D | 히어로 데모 카드(실제 문항). 은행 페이지는 로그인 없이 열린다 |
| P2 | 결과 약속 한 줄 + 주 CTA 하나, 옆에 조용한 '이미 계정이 있어요' 링크 | A·C·D | 히어로: **시작하기** + 보조 링크 '로그인' |
| P3 | 자료 → 자동 세트 → 모드 선택, 3단 흐름 | A·C | 작동 방식 StepRail(업로드·OCR은 '준비 중') |
| P4 | 번호가 붙은 학습 경로(단계마다 문항 수 표시) | B·C·D | 10단계 경로 레일(랜딩 §4, 대시보드 사이드바) |
| P5 | 모든 행에 같은 난이도 표기 | B·C | lv1~3 점 표기를 은행 카드·표·데모에 통일 |
| P6 | 활동 히트맵 + 연속일·활동일 작은 수치 3개 | C·D | 대시보드 위젯 1·3 |
| P7 | 즉시 피드백 → 틀린 문제는 자동으로 오답 목록에 들어가고 복습으로 돌아온다 | A·D | 랜딩 §3 원인 대비, 대시보드 '남은 오답' |
| P8 | 시간 제한 모드는 선택 사항이고, 벌칙(생명 차감)은 두지 않는다 | A·D | 타임어택 5/7/10/15초. 데모는 10초 1종 |
| P9 | 결과를 정확도와 속도로 나눠 보여준다 | B | 게임 결과·대시보드 정답률 표기 |
| P10 | 음성 입력 상태: 대기/듣는 중/처리 중, 항상 보이는 '지금은 말하기 어려워요' 대체 수단, 권한 거부 안내, 인식된 번호 되읽기 | D | `qb-voice.js`, 퀴즈·랜딩 데모 |
| P11 | 홈은 '이어서 하기'가 중심, 큰 '새 자료 올리기' 타일 | A·D | 대시보드 위젯 4·8 |

**차별점(4곳 모두 없음):** 보기 번호를 말로 고르기, 원본 자료 페이지가 붙은 힌트(h·src).

## 채택하지 않음

| 패턴 | 이유 |
|---|---|
| 히어로 옆 큰 사용자 수·평점 | 큰 숫자 히어로 금지, 근거 없는 수치 금지. 우리는 빌드 때 계산한 실제 문항 수를 문장으로만 쓴다 |
| '문서 올리기'를 주 CTA로 | 업로드는 아직 실제로 동작하지 않는다(과장 금지) |
| 리그·전체 순위, 생명(하트) | 사용자 규모가 작고, 학습을 막는 마찰이 된다. 개인 최고 기록만 쓴다 |
| 카테고리 메가 메뉴 랜딩 | 경로 하나, CTA 하나 원칙과 충돌 |
| 수량 제한 유료화 표시 | 지금은 유료 플랜이 없다 |
| 한 화면 한 질문 온보딩 / 배치 진단 | 다음 단계 후보로 남긴다(이번 범위 밖) |
