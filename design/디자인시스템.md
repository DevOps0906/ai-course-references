# 디자인 시스템 — Quiz Bank (v2)

> **v2 (2026-10-15)**: 사용자 요청에 따라 "작고 정돈된" 방향으로 개편했다.
> - 타이포는 AI_Voice day07 워크시트 수치(본문 15px / 행간 1.55, 요소 13~14px)를 따른다.
> - 다크 팔레트는 day07의 남색 + 앰버·틸이다.
> - 토큰 값의 원천은 [`tokens.css`](tokens.css)이며 빌드할 때 모든 페이지에 들어간다.
> - 수치 비교 근거는 [`구성요소_module1.md`](구성요소_module1.md)에 있다.

## 1. 원칙
1. **작은 글자, 정교한 대비**: 본문은 15px로 하고, 회색은 3단계(`--ink` / `--muted` / `--faint`)로 위계를 만든다.
2. **색은 아껴 쓴다**: 면 색은 정답·오답·선택 상태에만 쓴다. 유형은 3px 왼쪽 띠와 테두리형 배지로만 알린다.
3. **선으로 구분한다**: 그림자 대신 1px 선을 쓴다. 모서리는 8~10px, 알약 모양은 쓰지 않는다.
4. **숫자는 고정폭**: 점수·진행·시간은 tabular-nums로 쓴다. 영문 코드(자료 위치 배지·결과 코드·문항 번호)만 mono로 쓴다. 한글이 섞인 요소에 mono를 쓰면 자간이 벌어지므로 피한다.
5. **모바일은 엄지 기준**: 560px 미만에서 터치 높이 40px 이상, 하단 버튼은 꽉 차게, 게임 보기는 화면 아래쪽에 둔다.

**Hint**: 빨간색(`--bad`) 테두리형 토글 버튼. 펼치면 왼쪽 빨간 선 + 옅은 빨간 면 상자.

> **예외 (사용자 지정)**: 문제풀이(학습·오답 재도전)·**오답노트**·**해설지** 화면(`.sheet`)은 같은 규칙을 쓴다.
> - 글자 **10px**, 문제 문장 **11px**, 자간 **+0.03em**, 본문류 행간 **1.7**
> - 원래 크기 유지: 페이지 제목(h1 24px) · 탭 제목(h2 17px) · 오답노트/해설지의 탭 묶음 제목(14px)
> - 학습 탭 선택 버튼: 웹(≥1024px) 자유 배치 · 태블릿(560~1023px) 3개 · 모바일(<560px) 2개
> - 보기: 번호 → 라디오 → 글 순서
> - 홈·게임 화면은 위 표를 따른다.

글꼴은 **Pretendard Variable**(jsDelivr 동적 서브셋)을 쓰고, 없으면 Noto Sans KR → 시스템 글꼴 순으로 대체한다. mono는 JetBrains Mono → D2Coding → Consolas 순이다.

## 6. 모션 · 인쇄 · 접근성
- **모션**
  - 선택·판정 전환은 .12~.2s로 한다. 게임 판정 강조는 0.9초(오답은 1.4초) 동안 보여 준다.
  - `prefers-reduced-motion`이면 애니메이션을 끄고 타이머를 1초 단위로 줄인다.
- **인쇄**: 흰 배경 12.5px로 바꾸고 상단 바·버튼·탭 바·진행 바를 숨긴다. 카드는 페이지 경계에서 나뉘지 않게 한다.
- **접근성**
  - 포커스 표시는 2px `--link` 외곽선이다.
  - 키보드 조작: 게임은 1~5와 O/X로 답하고 Enter로 제출하며, 탭 바는 ←→로 이동한다.
  - 판정과 남은 5초를 `aria-live`로 알린다.

## 7. 토큰 v3 (3층)
`tokens.css`는 v3부터 세 층으로 나뉜다. 컴포넌트·새 페이지는 2·3층만 쓰고, 1층 원시 값은 직접 쓰지 않는다.
1. **Primitive (원시 값)**: `--teal-700`, `--navy-900`, `--slate-200` 같은 색 이름과 값만 있다. 테마와 무관하다. 글자용 진한 틸 `--teal-700 #0B6F66`이 여기에 추가됐다.
2. **Semantic (의미)**: `--color-background / surface / surface-raised / surface-muted / field / text / text-muted / text-faint / border / border-strong / heading / brand / brand-text / on-brand / accent / success / warning / danger / highlight / focus`. 라이트 값은 `:root`에, 다크 값은 `:root[data-theme="dark"]`와 `@media (prefers-color-scheme:dark){:root:not([data-theme="light"])}` 두 곳에 똑같이 둔다. 그 밖에 `--radius-sm/control/card/lg`(6/8/10/12), `--font-sans/mono`, `--space-1..8`(4·8·12·16·24·32·48·64), `--ease`, `--dur-fast`(120ms), `--dur`(200ms)가 있다.
3. **Component**: `--button-bg/border/text`, `--button-primary-bg/border/text`. 유형·타이머·난이도(`--ty-*`, `--timer-*`, `--lv1..3`), `--combo`, `--gold`, `--shadow`, `--fs-*`도 이 층에 둔다.

**Alias**: 파일 끝 블록이 v2 이름(`--bg` → `--color-background`, `--panel` → `--color-surface`, `--ink` → `--color-text`, `--muted`, `--faint`, `--line`, `--line-2`, `--soft`, `--title`, `--link` → `--color-brand`, `--accent`, `--ok`, `--bad`, `--btn-*`, `--pri-*`, `--r-sm/r/r-md/r-lg`, `--font`, `--mono`)을 시맨틱에 연결한다. 해석된 색 값은 v2와 같아서 `quiz.html` 같은 기존 페이지는 그대로 보인다. 새 코드는 alias를 쓰지 않는다.

**과목 토큰**: `--subject-it / -korean / -english / -science / -music / -art`. 채도를 낮춘 한 가지 색씩이며 라이트·다크 공통이다. 흰 면과 남색 면 양쪽에서 아이콘·띠 색으로 3:1 이상이다(글자색으로는 쓰지 않는다). 아이콘은 `icons.svg`의 `i-code / i-type / i-languages / i-flask / i-music / i-palette`.

**포인트색 한 개 규칙**: 상호작용 강조(선택·링크·포커스·진행·활성 탭)는 `--color-brand`(틸) 하나만 쓴다. 앰버(`--color-accent`)는 다크 제목, 경고, 하이라이트의 보조색이고 버튼·링크에 쓰지 않는다. 글자로 쓰는 틸은 `--color-brand-text`(라이트 #0B6F66, 대비 6:1).

**공용 컴포넌트**: `components.css`(앱 셸, 버튼, 필드, 표, 배지, 콜아웃, 단계 레일, 탭, 카드, 히트맵 등)는 시맨틱 토큰만 쓰며 대시보드·랜딩·로그인에 포함한다. `quiz.html`은 포함하지 않는다.

## 8. 공용 스크립트
`qb-core.js`(로그인·테마·과목), `qb-progress.js`(연속일·히트맵·XP), `qb-voice.js`(음성 선택)는 `build.py`가 자리표시자로 넣는다. 저장 키와 API는 [`develop/개발서.md`](../develop/개발서.md) §9~10에 있다. 벤치마킹에서 추린 패턴 메모는 `benchmark/patterns.md`에 추상화한 형태로만 둔다.
