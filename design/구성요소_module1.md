**해석**
- 참고 페이지는 **15px / 1.55를 기준으로 두고 거의 모든 요소를 13~14px**로 운영한다. 행간은 문서 전체에 1.55 하나만 쓰고, 코드 블록만 1.5다.
- module1이 크게 느껴지는 주된 이유는 네 가지다.
  - 보기·버튼이 16px이다(+2~3px).
  - O/X가 30px이다.
  - 제목이 최대 32px이다.
  - 카드 패딩이 크다.
- 참고 페이지에는 모바일 대응이 없다. 리디자인에서는 **데스크톱은 참고 페이지 수치를 그대로** 쓰고, **모바일만 본문 14.5px, 터치 높이 40px**을 보강한다.

**정리:** 전체적으로 글자를 1~2단계 줄이고, 굵은 색 띠·알약 버튼·큰 박스를 걷어낸다. 대신 얇은 선, mono 숫자, 작은 라벨로 정보 밀도를 높인다.

## C. "고급지고 세련된" 방향 제안

1. **글자는 줄이고 대비는 정교하게**
   - 본문 15px로 한다.
   - 회색 계열을 3단계(본문 / 보조 / 흐림)로 정리한다.
   - 숫자·코드·자료 위치는 mono로 써서 정돈된 느낌을 준다.
2. **색은 덜 쓰기**
   - 유형 배지를 '색 채움'에서 '얇은 테두리 + 색 글자'로 바꾼다.
   - 카드 왼쪽 띠를 6px에서 3px로 줄인다.
   - 정답·오답만 면 색을 쓴다.
3. **형태**
   - 알약 버튼을 8px 모서리로 바꾼다.
   - 카드 그림자를 없애고 1px 선만 둔다.
   - hover 시 테두리만 진하게 한다.
4. **다크 모드**
   - D7처럼 깊은 남색 바탕(#0B1220)에 패널 #111A2E를 쓴다.
   - 포인트 색은 앰버(제목)와 틸(링크·자료 위치) 두 가지로 한정한다.
5. **반응형**

   | 폭 | 기준 |
   |---|---|
   | ≥ 900px | 본문 880px, 홈 탭 카드 3열 |
   | 560~899px | 2열, 여백 20px |
   | < 560px | 1열, 여백 16px, 본문 14.5px, 터치 높이 40px 이상, 하단 버튼 꽉 차게, 짝 맞추기 위아래 배치 |
   | 게임 (모바일) | 보기 버튼을 화면 아래쪽에 모아 엄지로 누르기 쉽게, 타이머·HUD는 상단 고정 |

6. **유지할 것**: 기능·데이터·화면 흐름은 그대로 두고 **CSS와 마크업 일부만** 바꾼다. 문제은행 JSON은 건드리지 않는다.
