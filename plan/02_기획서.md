## 1. 배경과 문제
- `source/04-voice-ai`에는 Day마다 개념 워크시트가 있어 학습 확인이 잘 된다. **01~03 폴더에는 이런 장치가 없다.**
- 기존 워크시트는 HTML 파일마다 엔진이 복사돼 있어 새 자료에 적용하기가 어렵다.
- 저장, 오답노트, 해설지, 게임 요소가 없어서 한 번 풀고 나면 다시 볼 이유가 적다.

## 2. 목표

> **최종 목표**: 문서(PDF·TXT·Word)를 넣으면 자동으로 분석해 문제은행으로 바꾸고, 공부하기 좋은 학습 경험을 만들어 주는 학습 시스템. (개념은 [01_플랫폼_개념.md](01_플랫폼_개념.md) 참고)
> 1단계는 이 파이프라인(수집 → 분석 → 출제 → 검증 → 빌드)의 **모든 단계를 파일 기반으로 한 번 끝까지 통과**시키는 것이다. 사람(Claude Code)이 맡은 단계는 이후 하나씩 자동화한다.

| 구분 | 목표 | 측정 |
|---|---|---|
| 콘텐츠 | 자료 1개 → 문제은행 1개를 반복 가능한 절차로 만든다 | 출제 프롬프트 + 검증 통과 |
| 학습 | 자료의 핵심 개념을 빠짐없이 문항으로 덮는다 | 교안 빈칸·핵심정리 100% 반영 |
| 재방문 | 게임 모드와 오답노트로 다시 풀게 만든다 | 게임 플레이 수, 오답 극복 수 |
| 운영 | 새 자료 추가가 JSON 1개 + 빌드 1회로 끝난다 | 엔진 수정 없이 추가 |

## 3. 사용자
- **학습자 (주 사용자)**: 강의를 들은 직장인·교직원. 코딩을 모르며 PC와 모바일을 오간다.
- **강사/운영자 (본인)**: 자료를 넣고 문제를 검수하며 결과 코드로 제출을 확인한다.

## 4. 기능 명세

### 4.1 홈
- 문제은행 제목, 출처 자료, 문항 수, 탭 수를 보여준다.
- 탭 카드: 탭 제목, 자료 위치, 상태(미응시 / `8/10`)를 보여주며 누르면 해당 탭으로 이동한다.
- 진행률(채점 완료한 탭 / 전체 탭)과 오답노트 개수 배지를 표시한다.
- 버튼은 [학습 시작] [게임 모드 🔒] [오답노트] [해설지 🔒] 네 개다.
- 이름 입력란을 두며, 결과 코드와 순위 닉네임의 기본값으로 쓰인다.

### 4.2 모드 1 · 학습 (문제은행)
- 상단 탭 바(1~N)를 두며, 탭마다 10문항이 들어간다.
- 문항 카드: 번호, 유형 배지, 난이도 점, 문제, 응답 UI로 구성된다.
- 응답 유형:
  - `mc`: 하나 고르기
  - `multi`: 모두 고르기
  - `ox`: O/X
  - `match`: 선 잇기
  - `order`: 순서 맞추기
  - `num`: 숫자 입력
- **[이 탭 채점]**: 미응답이 있으면 목록을 보여주고 확인을 받는다. 미응답은 오답으로 처리한다.
  - 채점 후에는 카드마다 정답/오답, 정답 표시, 해설, 📖 자료 위치를 보여준다.
  - 탭 점수를 저장하고 오답을 오답노트에 추가한다.
- **[다시 풀기]**: 해당 탭만 초기화한다(보기 순서를 다시 섞는다).
- **종합 채점**: 모든 탭 채점이 끝나면 "종합 결과" 카드가 나타난다.
  - 총점과 백분율, 탭별·유형별 막대를 보여준다.
  - 결과 코드 `M1-B-3F9A2C`를 만든다.
  - 전체 오답 리포트를 클립보드로 복사할 수 있다.

### 4.3 오답노트
- 모드 1 채점과 모드 2 게임에서 틀린 문항이 `id` 단위로 쌓인다(중복 없이 틀린 횟수만 증가).
- 탭별로 묶어 보여준다. 각 항목에는 문제, 내가 고른 답, 정답, 해설, 자료 위치, 틀린 횟수가 들어간다.
- **[오답만 다시 풀기]**: 오답 문항만 모아 학습 모드처럼 풀고 채점한다. 맞힌 문항은 **극복 ✓** 표시를 하고 목록 아래로 내린다.
- [마크다운 복사]로 노션·메모에 붙여 넣을 수 있다. [인쇄]와 [극복한 항목 비우기]도 제공한다.

### 4.4 해설지
- 전 문항의 문제, 정답, 해설, 자료 위치를 탭 순서대로 나열한다.
- 인쇄 전용 레이아웃: A4 기준이며 카드가 페이지 경계에서 잘리지 않게 한다.
- **열림 조건**: 탭 1개 이상 채점. 해설지에는 그 탭의 해설만 나오고, 미응시 탭은 "채점 후 공개"로 가린다.

### 4.5 모드 2 · 게임

> **게임은 여러 종류로 늘어난다.** 게임 모드를 누르면 **게임 선택 화면(버튼 3칸)**이 먼저 나온다. GAME 1은 **타임어택**이고, GAME 2·3은 "준비 중" 자리로 비워 두었다가 새 게임을 추가할 때 채운다.

#### GAME 1 · 타임어택
- **열림 조건**: 모드 1에서 탭 1개 이상 채점 완료. 그 전에는 🔒 표시와 함께 "탭 하나를 먼저 풀어보세요"를 안내한다.
- **설정 화면**
  - **풀이 시간(문항당): 5초 / 7초 / 10초 / 15초** 중 선택 (기본 10초)
  - 문항 수: 10 / 20 / 30 / 전체(게임 가능 문항 수)
  - 출제 범위: 전체 탭 / 내가 풀어본 탭만 / 오답노트 문항 우선
  - 닉네임(기본값은 홈의 이름)
- **플레이 화면**
  - 상단: 진행(3/10), 점수, 콤보
  - 문제 아래에 **타이머 바**가 가득 찬 상태에서 0으로 줄어든다. 색은 남은 비율 50%↑ 초록, 25~50% 주황, 25%↓ 빨강으로 바뀐다.
  - 제한시간: 설정에서 고른 풀이 시간을 모든 문항에 똑같이 적용
  - 선택하면 즉시 판정한다. multi는 [제출]을 눌러야 판정한다.
  - 판정 후 정답을 0.9초 강조한 뒤 자동으로 다음 문항으로 넘어간다.
  - **시간이 다 되면 오답**으로 처리하고 "시간 초과"를 표시한다.
- **점수 규칙**
  - 정답: 기본 100점 + 남은 시간 1초당 10점
  - 콤보: 3연속부터 ×1.2, 5연속부터 ×1.5, 오답이면 콤보 초기화
  - 오답·시간 초과: 0점
- **결과 화면**: 최종 점수, 정답 수/전체, 정답률, 평균 응답시간, 최고 콤보를 보여준다.
  - 틀린 문항 목록(해설 펼치기)을 보여주고 오답노트에 자동 추가한다.
  - **순위표**: 이 브라우저의 TOP 10(점수 → 정답률 → 날짜 순)이며 내 기록을 강조한다.
  - 버튼은 [다시 하기] [오답노트] [홈] 세 개다.
- **순위는 같은 조건끼리**: 기록에 게임 모드와 풀이 시간을 저장하고, "타임어택 7초"처럼 같은 조건의 기록끼리만 순위를 매긴다.
- **순위 확장 (2단계)**: 저장소를 `Leaderboard` 인터페이스(`load()`, `add(record)`)로 감싸 둔다. 나중에 공유 저장소(Artifact DB 또는 서버)로 바꿔 끼우면 반·조 단위 순위가 된다.

### 4.6 공통
- 라이트/다크 자동 전환과 수동 토글을 지원한다.
- 키보드 조작: 숫자 1~5는 보기 선택, O/X 키, Enter는 제출/다음이다.
- 저장은 localStorage(은행 `id`별 네임스페이스)를 쓰며, 실패해도 페이지는 정상 동작한다.
- [기록 초기화] 버튼: 해당 문제은행의 진행, 오답, 순위를 삭제한다(확인 후).

## 5. 비기능 요구
| 항목 | 기준 |
|---|---|
| 배포 | 단일 HTML. 서버·설치 불필요. 외부 리소스는 Google Fonts만 쓴다(오프라인이면 시스템 글꼴) |
| 호환 | 최신 Chrome/Edge/Safari, 모바일 375px 폭 |
| 접근성 | 대비 AA, 포커스 표시, `prefers-reduced-motion`이면 타이머 애니메이션 단순화 |
| 보안 | 정답이 페이지에 들어 있는 것은 학습용이라 허용한다(기존 워크시트와 동일). 결과 코드로 단순 위조만 막는다 |
| 정리 규칙 | 문항에 기관명·개인명을 넣지 않는다. `tools/check.py` 통과 |

## 6. 로드맵
| 단계 | 내용 | 산출물 |
|---|---|---|
| **1단계 (지금)** | 기획·디자인·개발 문서, 엔진, 문서 수집기(`ingest.py`), 모듈1 60문항 | `develop/dist/01-ai-work/ai-automation/module1.html` |

| 5단계 | **학습 시스템 웹앱**: 문서 업로드 UI, 내 문제은행 목록, 진행률, 공유 순위, source/04-voice-ai 워크시트 이관 | 최종 목표 달성 |

## 7. 리스크
