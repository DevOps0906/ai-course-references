## 2. 워크시트 — 템플릿이 두 종류

| 항목 | D1 | D2 ~ D7 |
|---|---|---|
| 문제 저장 | `const Q=[…]` 평면 배열 15개 | `const Q=[{t,anim,qs:[…]}]` 교시별 묶음 |
| 필드명 | `t,p,q,o,a,e` | `ty,p,o,a,w,an` |
| 유형 | mc · multi · ox · match · order · **num** | mc 5 · ox 2 · match 1 · order 1 · multi 1 (교시당) |
| 채점 | 전체 한 번 (미응답 있으면 막음) | 교시 탭별 (미응답은 오답 처리) |
| 결과 | 점수 · 유형별 막대 · 인쇄 | 결과 코드(`hash`) · 오답 표 · 노션 복사 |
| 테마 | 라이트/다크 자동 | 다크 전용 |
| 글꼴 | IBM Plex Sans KR | Pretendard (로컬) |

D2~D7 파일끼리는 **제목·문제 데이터·해시 salt 등 5줄만 다르다.** 즉 이미 "엔진 + 데이터" 구조가 숨어 있고, 이를 분리하기만 하면 된다.

### 재사용할 로직
- 채점: D1 `isCorrect`(num 허용오차, multi 순서 무관), D2 `correct()`
- 섞기: D1 `shuffledIdx` — 섞은 결과가 정답 순서와 같지 않도록 보장
- 연결하기 UI: D1 SVG 선 연결
- 결과 코드: D2 djb2 `hash(name|tab|score|salt)`
- 리포트 복사: D2 3단계 클립보드 대체 경로 (copy 이벤트 → ClipboardItem → textarea)

## 3. 애니메이션
- Canvas 2D와 Web Audio만 쓰며, 외부 라이브러리 없이 파일 하나로 동작한다.
- 탭은 `#hash` 딥링크를 지원한다(`animation.html#sampling`).
- 워크시트와는 **텍스트로만 연결**된다. `an` 필드에 "D2-3 · 샘플링 슬라이더"처럼 적혀 있을 뿐, 코드 링크는 없다.

## 4. 비어 있는 것 (플랫폼이 채울 부분)
| 없음 | 영향 |
|---|---|
| 저장(localStorage) | 새로고침하면 진행·결과가 사라짐 |
| 오답노트 | 틀린 문제를 다시 모아 볼 방법이 없음 |
| 해설지 | 해설이 채점 후 카드 안에만 흩어져 있음 |
| 게임/타이머 모드 | 반복 학습의 동기 부여 장치가 없음 |
| 순위 | 경쟁 요소 없음 |
| 공용 엔진 | 14개 HTML에 같은 코드가 복사돼 있음 → 수정 시 14곳 |
| 문제 메타데이터 | 난이도·고유 id·출처 위치가 없음 |
| 다른 과목 적용 | 01~03 폴더에는 워크시트가 하나도 없음 |

## 5. 결론
1. 문제는 **JSON 문제은행**으로 분리하고, 화면은 **공용 엔진 하나**가 그린다.
2. 필드는 D2~7 형식(`ty,p,o,a,w,an`)을 기본으로 삼고 D1의 `num` 유형을 흡수한다. 여기에 `id`, `lv`, `game`을 추가한다.
3. 디자인은 D1 + 애니메이션의 라이트/다크 토큰으로 통일한다.
4. 새로 만드는 기능은 저장, 오답노트, 해설지, 게임 모드, 순위다.
