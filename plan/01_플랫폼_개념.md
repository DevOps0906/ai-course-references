# 01. 플랫폼 개념

## 최종 목표 (North Star)
> **문서(PDF · TXT · Word)를 넣으면 자동으로 분석해서 문제은행으로 바꾸고, 공부하기 좋은 학습 경험(학습 · 게임 · 오답노트 · 해설지)을 만들어 주는 학습 시스템.**

이 저장소의 강의자료(01~04)는 첫 번째 시험 대상일 뿐이다. 모든 설계는 **"임의의 문서 한 개"**를 입력으로 가정한다.

```
 문서 투입         ① 수집(ingest)     ② 분석(analyze)       ③ 출제(generate)     ④ 검증       ⑤ 빌드 → 학습
 PDF/TXT/DOCX ─▶ 텍스트·구조 추출 ─▶ 단원·핵심개념 지도 ─▶ 문제은행 JSON ─▶ validate ─▶ 단일 HTML
 (MD·IPYNB)      develop/ingest.py   outline.json         출제 프롬프트       .py          build.py
```

| 단계 | 1단계(지금) | 최종 |
|---|---|---|
| ① 수집 | md는 그대로, pdf/txt/docx는 `ingest.py`로 md 변환 | 업로드 즉시 자동 변환 (스캔 PDF는 OCR) |
| ② 분석 | Claude Code가 자료를 읽고 탭(단원) 구성 | 개념 지도 자동 생성 → 탭·난이도 배분 자동 |
| ③ 출제 | Claude Code가 `출제_프롬프트.md`대로 JSON 작성 | 같은 프롬프트를 Claude API로 자동 실행 |
| ④ 검증 | `validate.py` + 사람 검수 | 자동 검증 + 2차 AI 검수(근거 대조) + 선택적 사람 검수 |
| ⑤ 학습 | 단일 HTML (file://) | 웹앱: 문서 업로드 → 내 문제은행 목록 → 학습/게임/공유 순위 |

**설계 원칙**: 각 단계는 **파일로만 주고받는다**(md → json → html). 그래서 어느 단계든 사람에서 자동화로 하나씩 바꿀 수 있다. 엔진과 스키마에는 특정 과목 전제를 넣지 않는다.

## 한 문장 정의 (1단계)
> **자료(md 또는 pdf·txt·docx를 변환한 md)를 넣으면 문제은행(JSON)이 만들어지고, 그 문제은행 하나로 "학습 모드"와 "게임 모드"를 모두 돌리는 정적 웹 플랫폼.**

## 구조 — 4개 층

```
 ┌───────────────┐   출제(Claude Code)   ┌──────────────┐   빌드    ┌──────────────────┐
 │ ① 원본 자료     │ ───────────────────▶ │ ② 문제은행     │ ───────▶ │ ③ 엔진 + 은행      │
 │ 01~04 폴더 md  │  prompts/출제_프롬프트 │ banks/*.json │ build.py │ dist/*.html (단일) │
 └───────────────┘                       └──────────────┘          └────────┬─────────┘
                                          validate.py 로 검사                  │ 브라우저
                                                                    ┌──────────▼─────────┐
                                                                    │ ④ 학습자 경험        │
                                                                    │ 학습 · 게임 · 오답노트 │
                                                                    │ 해설지 · 순위         │
                                                                    └────────────────────┘
```

| 층 | 책임 | 바뀌는 빈도 |
|---|---|---|
| ① 원본 | 강의 내용. 이 저장소의 01~04 폴더 (`tools/sync.py`가 관리) | 원본 업데이트 시 |
| ② 문제은행 | 문항·정답·해설·자료 위치·난이도. **콘텐츠의 유일한 원천** | 자료 1개당 1회 + 보강 |
| ③ 엔진 | 화면·채점·저장·게임 규칙. **모든 과목이 공유** | 기능 추가 시 |
| ④ 경험 | 학습자가 실제로 만나는 페이지 | — |

## 핵심 원칙
1. **콘텐츠와 엔진 분리**: 문제를 고칠 때는 JSON만, 기능을 고칠 때는 엔진만 수정한다.
2. **파일 하나로 열린다**: 기존 워크시트처럼 더블클릭(file://)으로 열리게 한다. 서버, 설치, 로그인이 없다.
3. **모든 문항은 자료로 돌아간다**: `an` 필드로 "어디서 배웠는지"를 반드시 가리킨다.
4. **사람이 검수한다**: 출제는 AI가 하지만 `validate.py`와 사람의 검토를 거쳐야 은행에 들어간다.
5. **점진적 확장**: 01 → 02 → 03 → (04 이관) 순서로 자료를 하나씩 넣는다.

## 두 가지 학습 경험

| | 모드 1 · 학습 (문제은행) | 모드 2 · 게임 (타임어택) |
|---|---|---|
| 목적 | 개념을 빠짐없이 확인 | 반복·인출 연습, 동기 부여 |
| 구성 | 탭당 10문항 × N탭 | 문항 수 선택 (10/20/30/전체) |
| 시간 | 제한 없음 | 문항당 10~15초, 바가 줄어듦 |
| 유형 | 전 유형 (mc·ox·multi·match·order·num) | 빠르게 풀 수 있는 유형 (mc·ox·multi) |
| 채점 | 탭별 + 마지막에 종합 | 즉시 판정, 시간 초과 = 오답 |
| 결과 | 점수·유형/탭별 분석·결과 코드 | 점수(정답+시간 보너스+콤보)·순위 |
| 열림 조건 | 항상 | **모드 1에서 탭 1개 이상 채점 완료** |

두 모드의 오답은 **같은 오답노트**로 모인다. 해설지는 모드 1에서 채점을 한 번 마치면 열린다.

## 학습 루프

```
 자료 읽기 → 모드1 탭 풀기 → 채점·해설 → (잠금 해제) → 모드2 게임
      ▲                         │                      │
      └──── 📖 자료 위치 ◀── 오답노트 ◀──────────────────┘
```

## 용어
| 용어 | 뜻 |
|---|---|
| 문제은행(bank) | 자료 1개에서 나온 문항 묶음 JSON. 여러 탭(tab)으로 구성 |
| 탭(tab) | 10문항 묶음. 자료의 한 단원/교시에 대응 |
| 문항(question) | 고유 `id`를 가진 문제 1개 |
| 자료 위치(`an`) | 문항이 근거로 삼는 원본 위치 (예: `1-2 §2 R-C-T-F-C 표`) |
| 결과 코드 | 이름·탭·점수로 만든 짧은 확인 코드 (위변조 확인용) |
